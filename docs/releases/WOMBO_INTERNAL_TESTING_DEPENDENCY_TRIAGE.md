# Dependency security triage

2026-11-04. Final software `8f75140169e074111e868d48bcf67e82aed8f899`. Original locked tree: 47 npm production-tree findings (1 critical, 10 high, 31 moderate, 5 low). Targeted candidate: **42 findings, 0 critical, 6 high, 31 moderate, 5 low**. No critical/high risk was automatically accepted. Expo SDK, React Native and native module versions were not upgraded.

## Exact changes and verification

Seven scoped npm override entries pin compatible families: shell-quote 1.11.0; xmldom 0.8.15 and 0.9.12 for their existing respective families; brace-expansion 1.1.21 and 5.0.12; node-forge 1.4.3; source-map-js 1.2.2. Only ten existing package nodes changed versions. No other package node was added/removed/upgraded. The lockfile records exact registry integrity. A fresh isolated `npm ci --ignore-scripts --no-audit --no-fund` installed 952 packages.

`node mobile/scripts/verify-dependency-security.cjs` passes deterministic checks for rejecting newline-after-comment shell tokens without executing them, normal quote/parse round-trips, XML/plist round-trip, both brace-export families, SHA-256 and source-map resolution. Full mobile tests, Metro/Hermes and native verification add regression coverage. No audit fix command or global upgrade ran.

Counts are npm advisory classifications of package nodes/aggregate effects, not counts of independent exploitable app vulnerabilities. `expo-router`, `query-string` and `@expo/cli` inherit high severity from dependencies; their aggregate entries must not be double-counted as separate primary flaws. Original and post-patch sanitized metadata, paths and release-map presence are retained in `evidence/remediation/`.

## Remaining-risk proposal — owner decision required

The runtime decoder chain is demonstrably bundled and has a plausible external-link entry point. **Do not mark it accepted on the basis of two testers, test success or exclusion of build-only modules.** Preferred resolution is a reviewed SDK-57-compatible upstream/backported CJS fix, or an explicitly scoped router migration with deep-link/Unicode/malformed-input regressions and a new native build. This task does not claim such a fix exists or invent a URL-size policy.

For image-size/Zod/CLI tooling, a possible temporary exception would name the exact lock/software SHA, advisory IDs, trusted-source-only asset/config policy, isolated build environment, no externally exposed dev server, accountable owner/security reviewer, expiry and trigger for upstream patch review. Record whether tool inputs can be attacker controlled in the actual build process. This is a **proposal**, not accepted risk. The remaining moderate/low findings are retained in evidence and are not silently declared harmless.

No critical/high acceptance record was supplied. Security therefore remains an independent NO-GO gate even if native compilation succeeds.
