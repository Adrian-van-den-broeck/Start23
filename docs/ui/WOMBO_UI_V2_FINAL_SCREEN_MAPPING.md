### Precise Week derivation (no dedicated mockup supplied)

At reference width: M6 title/Profile arrangement, 140 dp faded landscape, 12 dp from title block to week range/state, 16 dp to first ivory card. Active card uses M5 sport/title/metric anatomy with forest detail CTA; it is not the old full-forest hero. Pending/draft/no-plan use WeekTaskCard. Same-day siblings follow at 12 dp, each independently actionable. Progress is plain supporting text 12 dp below; View week is an icon ActionRow. Attention follows at 24 dp, retaining current priority/count/show-all behavior. Training tools form one ivory row group with dividers, then supplied goal row at 24 dp. No new week arrows/countdowns/summary metrics unless already in that Week state. Active+pending: keep active workout card and a separate pale pending-review task row, never substitute pending workouts into Today. All dimensions yield to text growth.

### Cross-family state rules, including uncaptured variants

| State | Visual delta | Preserved semantics |
| --- | --- | --- |
| Loading | Static skeleton within actual card/row footprint; one status label. | No fake dates, counts, prescriptions or pending success; no duplicate request from new wrapper. |
| Empty | Existing empty copy in one ivory group; relevant existing action; no empty chart. | Distinguish absence, not loaded, failure and prescribed rest. |
| Saving | Stable labeled button/choice plus spinner/status; existing locks. | Do not advance saved count or remove pending state early. |
| Error | Destructive Notice near affected group; preserve entered values and safe error copy. | No raw exception/private data; only currently supported retry/return. |
| Stale | Warning/Info Notice with existing refresh/review action; invalid decisions disabled. | Exact revision/precondition; no silent retry with newer version or last-write-wins. |
| Unknown write outcome | “Not yet confirmed” state via existing safe localized copy; keep object identity. | Reconcile using current owner/idempotency key; no second create. |
| Missing optional data | Omit metric row and close gap; helper when workflow requires it. | Missing never becomes zero, inferred duration or speculative physiological value. |
| `values_hidden` | Omit numeric table and inaccessible descendants; show supplied visibility explanation. | No concealed values in labels, logs, test screenshots or accessibility. |
| Long content | Wrapping, taller cards, continuation in same scroll owner. | No clipped warnings, targets, last field, confirmation or sibling. |

These are design rules for existing state capabilities, not additional captured screenshots. For unsupported behavior stop at the visual pattern and record the missing product decision.
